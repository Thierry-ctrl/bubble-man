# Superseded results (v1), kept for traceability

Produced 29 September 2026, before four corrections:

1. Delay was measured from the START of an unusual run, not from the moment an alert
   could actually be issued. v1 delays are therefore too short.
2. Unmatched warnings were described as "late detections of genuine leakage". Nothing
   linked them to a leak; only that a leak happened to be running.
3. Zones were inferred from before/after flow steps, not from the network map.
4. Whole-week rotation was said to preserve seasonality. It does not.

Do not quote these numbers. They are here so the change can be traced.
